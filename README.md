# Lista de Tarefas

## Sobre o projeto

Este é um programa simples de lista de tarefas feito em Python com auxílio de Inteligência Artificial.

O programa permite:

- Adicionar tarefas;
- Listar tarefas;
- Concluir tarefas;
- Remover tarefas;
- Salvar as tarefas em um arquivo JSON.

## Como executar

É necessário ter o Python instalado.

No terminal, execute:

```bash
python app.py
